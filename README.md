# 命学约言技能包 · v1.0

清初陈素庵《命理约言》（民国韦千里精选本）的断法蒸馏技能包：五席技能覆盖「看命总纲 → 十神格局 → 变格辨妄 → 断事 → 性情疾病女命小儿」全链路，给定四柱八字即可按原书法度逐层检索断语。

不是读书笔记，不是摘要——是**一套建立在四柱八字模型之上的断法规则系统**。由「命学真典」流程蒸馏：全书 20 块 × 五路提取 1,105 条候选，四层验证（原文支撑 / 模型路径 / 规则一致性 / 命例交叉）零淘汰，双层诱饵盲测 21/21 通过。

| yueyan-shishen | 十神格局断法：正官/七杀/**官煞去留**/印/财/食神/伤官/比劫禄刃，各格行运细则 | 179 条规则 |

## 本书特色（为什么值得装）

1. **官煞去留三篇**：官杀混杂怎么「去一留一」（干去/支去/会局去/入库去/干支合力去），本书独有专论，他书无此系统。
2. **取格降级链**：月令本气透→所藏→别干势盛，取格有明确机械步骤，治「格局全靠感觉」。
3. **外格辨妄清道夫**：三奇/双美/十恶大败/壬骑龙背/六乙鼠贵/金神/魁罡……三十余种旧格逐条论证「无据不取」，并给出该按什么重断——装一个技能包，省一次被伪格忽悠。
4. **干支一气十组**（四甲戌~四癸亥）：全书最接近命例的干货，逐组逐运行运吉凶。
5. **犯太岁之辨**：日干犯岁为偏财、合岁为财官，衰旺定吉凶——直接推翻「犯太岁必凶」民俗断法。

## 使用方式

给助手一个八字排盘（四柱天干地支）+ 性别，然后按问题问：

- 整体分析 → kanning｜「帮我从头看这个八字」
- 格局与十神 → shishen｜「官杀混杂怎么去留」
- 从格化格/伪格 → biange｜「满盘是水能不能从」「壬骑龙背可信吗」
- 富贵寿夭六亲 → duanshi｜「这辈子什么层次」
- 性格健康女命小孩 → xingqing-nvming｜「容易出什么毛病」
